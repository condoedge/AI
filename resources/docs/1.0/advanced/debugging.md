# Debugging the AI Pipeline

Trace and diagnose issues across the full AI pipeline using the built-in `AiLogger`.

---

## Enable Debug Mode

Add to `.env`:

```env
AI_DEBUG=true
AI_LOG_CHANNEL=single
```

When `AI_DEBUG` is false (the default), the logger only records warnings, errors, fallback decisions, and high-level pipeline events. When true, every intermediate decision is logged.

---

## What Gets Logged

### Always logged (any mode)
- Pipeline start/end with duration
- Fallback decisions (semantic &rarr; keyword &rarr; full schema)
- Errors in any service
- Context quality assessment (high/medium/low)

### Debug mode only (AI_DEBUG=true)
- Every semantic search result with score
- Threshold filtering decisions (what was kept vs rejected)
- Selected entities, relationships, scopes with scores
- Entity expansion through relationships
- Similar queries found with top scores
- Schema filtering details
- LLM prompt size and response
- Template matching attempts in QueryGenerator
- Retry reasons and validation results

---

## Trace a Question

Every pipeline run gets a unique `ai_trace_id` (ULID). Filter your logs:

```bash
grep "ai_trace_id.*01JXXXXXX" storage/logs/laravel.log
```

The trace ID is generated by `AiLogger::startTrace()` and included in every log entry for that pipeline run, making it easy to follow a single question through all services.

---

## Tuning Thresholds

With debug mode on, look for `below_threshold` entries:

```
[AI] semantic_selector: result below threshold, rejected {"type":"entity","entity":"Order","score":0.6234,"threshold":0.65}
```

If relevant entities are being filtered out, lower the threshold:

```env
AI_SEMANTIC_CONTEXT_THRESHOLD=0.55
```

---

## Context Quality Assessment

Every context retrieval logs a quality indicator:

```
[AI] context_retriever: context_quality: high {"score":"4/4","details":["has_similar_queries","has_schema","has_detected_entities","no_errors"]}
```

Quality levels:
- **high** (4/4) — all context sources working
- **medium** (2-3/4) — some degradation, results may be less accurate
- **low** (0-1/4) — significant context missing, consider re-indexing

The quality object is also returned in the context array (`$context['quality']`), so you can inspect it programmatically.

---

## Configuration

| Variable | Default | Description |
|----------|---------|-------------|
| `AI_DEBUG` | `false` | Enable detailed pipeline logging |
| `AI_LOG_CHANNEL` | `null` | Laravel log channel (`null` = default channel) |
| `AI_SEMANTIC_CONTEXT_THRESHOLD` | `0.65` | Semantic similarity threshold |
| `AI_EMBEDDING_VECTOR_SIZE` | `null` | Override embedding dimensions |
