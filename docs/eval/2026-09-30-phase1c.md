## Regressions vs BASELINE (root cause)

1. **french t0, -0.20: INFRA, then composition.**
   - Qdrant 408 made context fall back to full_schema.
   - Without semantic selection, the generator anchored on TeamRole with an OPTIONAL User, which produced 2 orphan TeamRole rows with null names (525 rows).
   - The distinct-anchor line did its job ("use 523"), but the LLM overrode it with "525 distincts" and misstated the shown count (8 vs 10). french t1 inherits the blank rows (-0.10 vs p1/p1b).
   - **Fixes:**
     - Surface semantic-selection fallbacks in trace `context_errors` and classify them as INFRA.
     - Drop all-null display-name rows before composition and export, or require a User anchor for roster queries.
     - Have the truncation-honesty guard check the stated total against `anchor_total` and the listed count against the rows actually rendered.
2. **rights t1, -0.15: a retrieval ranking change since p1, not 1.28.**
   - **Baseline** chunk scores were distinct (1.063 / 0.992 / 0.942) and included **chunk 1071-1073**.
   - **From p1 onward**, every law chunk has the **identical score 0.5560599…**, and how-to chunks score 0.016 (an RRF-like 1/(60+k) shape).
   - Within-file relevance ordering is therefore lost. The file header chunk 0 (1009-1022) and 1038-1048 now fill the slots.
   - Also since p1, QU has tagged this legal turn `entity_types [Union, Invoice, Bill]` / `intent lookup` (baseline had `[]` / `other`). That injects "Current Focus: Bill" and Bill action links into a legal prompt.
   - **Fixes:**
     - Restore per-chunk relevance scores within a file after fusion.
     - Down-weight a law file's header chunk 0.
     - Add neighbour-chunk expansion.
     - Let the model use prior-turn article text by file name (the instruction already allows it; make that explicit for legal follow-ups).
   - The Phase 7 article-centered snippets are still the right long-term fix.
3. **rights t0, -0.10: LLM variance.** Retrieval is identical and no 1.28 change touches t0. The new defect is the wrong approval threshold ("majority" vs the 3/4 in 1097), plus the `action://docs` link. Needs a post-generation legal claim / threshold check against the cited chunk.
4. **digest t0, -0.05: composition unchanged since p1.** Needs a deterministic empty line outside sections, the union on the meeting fallback, no "None pending." when fallback rows exist, section links, and one offer.

**No 1.28 change shows a negative effect.** The snippet cap is the only change that touched these turns' prompts, and it raised rights t1.
